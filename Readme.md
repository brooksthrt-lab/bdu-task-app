# BDU Full-Stack Task Tracker 📚

A full-stack CRUD web application built with **HTML, CSS, JavaScript, Python (Flask), and SQL (SQLite)**.

## Features
- Create, view, and delete tasks asynchronously using JavaScript `fetch()` API
- Persistent storage powered by SQLite3 (`INSERT`, `SELECT`, `DELETE`)
- Clean RESTful JSON endpoints built in Flask

## How to Run Locally
1. Clone the repo:
   `git clone https://github.com/brooksthrt-lab/bdu-task-app.git`
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the server:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.
